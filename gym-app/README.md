# GymQuest 💪 — тренировки с геймификацией

Простое приложение для Android (PWA): готовые тренировки, XP, уровни, серии дней и достижения. Всё сохраняется локально на телефоне, работает офлайн, ничего никуда не отправляется.

## Тренировки

| Тренировка | Что внутри |
|---|---|
| 🧘 Функциональный пилатес | Со своим весом: планки, dead bug, bird dog, мосты (~30 мин) |
| 🏋️ Гантели: всё тело | Простая база: гоблет-присед, тяги, жимы (~40 мин) |
| 🦵 Восстановление колена | Укрепление после разрыва мениска, щадящие упражнения (~25 мин) |
| 🔩 Грудь и жим лёжа | Штанга + гантели: жим лёжа, наклонный жим, разводка (~45 мин) |

⚠️ Программа восстановления колена — только после согласования с врачом/физиотерапевтом.

## Геймификация

- **XP** за каждое упражнение + бонус +20 XP за полностью выполненную тренировку
- **Уровни** — каждый следующий требует больше XP
- **Серия (🔥 streak)** — дни тренировок подряд
- **10 достижений** — от «Первый шаг» до «Машина» (50 тренировок)
- **История** последних тренировок

## Как поставить на Android

Вариант 1 — GitHub Pages (рекомендуется):
1. В настройках репозитория: Settings → Pages → Deploy from branch → выбрать ветку и папку `/gym-app` (или корень).
2. Открыть полученную ссылку в Chrome на телефоне.
3. Меню Chrome (⋮) → **«Добавить на главный экран»** / «Установить приложение».
4. Готово — иконка на рабочем столе, работает как обычное приложение, даже офлайн.

Вариант 2 — локально: открыть `index.html` в любом браузере (без установки и офлайн-кэша).

## Данные

Прогресс хранится в `localStorage` браузера. Если очистить данные сайта — прогресс сбросится.

## Кастомизация

Все тренировки — в массиве `WORKOUTS` в начале `<script>` в `index.html`. Можно менять упражнения, подходы, XP или добавлять новые тренировки — формат очевиден из существующих.
