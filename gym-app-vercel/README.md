# GymQuest — версия для Vercel с облачной базой

То же приложение, что в `gym-app/`, плюс синхронизация всего прогресса (XP, тренировки, история, свои программы) в облако. Один пользователь, без регистрации.

## Как это работает

- Весь стейт хранится одним JSON-документом в **Vercel KV (Upstash Redis)** под ключом `gymquest:state`
- `api/state.js` — serverless-функция: `GET` читает стейт, `PUT` сохраняет
- Клиент грузит стейт при старте (облако приоритетнее localStorage) и пушит изменения с дебаунсом 800 мс
- Индикатор в шапке: ☁️ — синхронизировано, 💾 — только локально (база не подключена или нет сети)
- localStorage остаётся как офлайн-кэш — без сети всё работает, при появлении сети дольётся

## Подключение базы (один раз)

1. Vercel Dashboard → проект → **Storage** → **Create Database** → **Upstash (Redis/KV)**
2. Подключить к проекту (Connect) — переменные `KV_REST_API_URL` / `KV_REST_API_TOKEN` добавятся сами
3. Передеплоить проект (Deployments → Redeploy), чтобы функция увидела переменные

Без базы приложение тоже работает — просто хранит всё локально (💾).

## Защита PIN-кодом (опционально)

Кто угодно со ссылкой может читать/писать данные. Если нужно закрыть:

1. Vercel → проект → Settings → Environment Variables → добавить `APP_PIN` = любой код
2. Redeploy. При первом открытии приложение спросит PIN и запомнит его на устройстве.

## Деплой вручную

```bash
npm i -g vercel
cd gym-app-vercel
vercel --prod
```

Никаких зависимостей и сборки — статический `index.html` + одна функция.
